# NEXUS-COVE Plugins Directory

This is the canonical location for NEXUS-COVE related plugins.

## Contents

- **`nexus-cove-enhancement/`** — A Claude Code plugin providing hooks and TypeScript types for NEXUS-COVE integration.

## Archived (moved to `archive/`)

The following directories were consolidated here from the repo root:

- **`archive/NexusCove_Skills_Plugins_Installers_v3/`** — Installer scripts for setting up Claude Code skills and plugins (Chromium, required/optional skills, superpowers plugin). These are *installer scripts*, not the plugins/skills themselves.

- **`archive/pack_v3/`** — A packaged artifact containing `.claude/` (skills, hooks, settings) and `src/nexus_cove/` (agent code). This appears to be a distribution package.

## Note

The contents of the archived directories have NOT been merged. They remain in their original structure under `archive/` for reference. If you need to use the installer scripts, run them from `archive/NexusCove_Skills_Plugins_Installers_v3/`.
